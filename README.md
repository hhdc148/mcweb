项目简介

Minecraft Web 是一个完全运行在浏览器中的 Minecraft 复刻项目，不依赖任何后端服务，也无需安装客户端。整个项目使用原生 HTML / CSS / JavaScript 编写，仅引入 Three.js 作为 3D 渲染引擎，力求在 Web 端还原经典沙盒游戏的核心体验。

与许多"只能走两步看看风景"的 Web 演示不同，本项目实现了完整的游戏循环：世界生成 → 采集资源 → 合成工具 → 建造庇护所 → 生存下去。同时提供创造模式与丰富的调试工具，方便研究与二次开发。

项目的目标不是 1:1 像素级复刻，而是在性能、可玩性与代码可读性之间取得平衡，让任何对体素渲染感兴趣的人都能读懂并改造它。

功能特性

🎮 游戏模式

模式 说明
生存模式 拥有生命值与饥饿值，需要采集资源、合成工具、维持生存
创造模式 无限方块、自由飞行、内置背包与完整配方系统，专注建造

🧱 世界与渲染

· 基于区块（Chunk）的体素地形生成，支持无限延展
· 平滑光照（Smooth Lighting）可开关，兼顾观感与性能
· 面剔除（Face Culling）优化，大幅减少不可见面的绘制
· 可调渲染距离，适配从低端笔记本到高性能台式机的各种设备
· 实时 FPS 显示，便于观察性能变化
· 天空盒与全景背景图，营造沉浸式氛围

⚒️ 合成与冶炼

· 完整的合成台系统，按类别组织配方（建筑方块、装饰、工具、武器等）
· 熔炉冶炼玩法，支持矿石烧炼与燃料消耗
· 背包系统，支持拖拽、堆叠与快速移动物品

🧭 命令与调试

· 可开启作弊模式，使用内置命令控制世界
· 通过 /help 查看全部可用命令
· 常用命令如切换时间、天气、游戏模式、传送坐标等

💾 存档系统

· 支持创建新世界并自定义种子与模式
· 本地存档读取，随时回到上次的世界
· 保存并退出，进度不丢失

⚙️ 可调节设置

· 渲染距离
· 视场角（FOV）
· 背景音乐开关与音量
· 音效开关与音量
· 平滑光照
· FPS 显示
· 更多选项持续增加中

📊 实时状态面板

游戏内 HUD 实时显示：

· ❤️ 生命值 / 🍗 饥饿值
· 📍 当前坐标（X / Y / Z）
· 🎞️ 实时 FPS
· 🐷 当前生物数量
· 🔺 渲染面数
· 🧩 已加载区块数

快速开始

环境要求

只需要一个现代浏览器（Chrome / Edge / Firefox / Safari 均可），无需 Node.js、无需构建步骤。

方式一：直接打开

克隆仓库后，双击 index.html 即可运行。

```bash
git clone https://github.com/hhdc148/mcweb.git
cd mcweb
```

⚠️ 部分浏览器（尤其是 Chrome）会对 file:// 协议下的模块加载与纹理读取施加限制。若出现白屏或资源加载失败，请改用下面的方式二。

方式二：本地服务器（推荐）

```bash
# 使用 Python 3 内置服务器
python -m http.server 8080

# 或使用 Node.js 的 serve
npx serve .

# 或使用 PHP
php -S localhost:8080
```

然后打开浏览器访问：

```
http://localhost:8080
```

开始游戏

1. 在首页点击 「创建世界」
2. 输入世界名称，选择游戏模式（生存 / 创造）
3. 点击开始，进入 game.html 开始游玩

游戏系统详解

世界生成

地形基于噪声算法生成，包含地表、山脉、水域与地下矿层。世界按区块划分，仅加载玩家周围一定范围内的区块，超出渲染距离的区块会被卸载以节省内存。

生存循环

1. 采集：徒手或使用工具破坏方块，获取原木、石头、矿石等资源
2. 合成：打开合成界面，将原材料组合成工作台、工具、火把等
3. 冶炼：使用熔炉烧炼铁矿、烹饪食物
4. 建造：利用方块搭建庇护所，抵御夜晚
5. 生存：关注生命值与饥饿值，合理分配资源

命令系统

开启作弊模式后，可按下 T 或 / 唤出控制台。输入 /help 可查看所有命令。命令系统适合快速测试与搭建场景，也方便开发者调试。

存档机制

存档保存在浏览器本地存储中。每个世界记录种子、玩家状态、已修改方块与游戏模式。选择「保存并退出」后，下次可从首页直接读取。

开发与调试

· 修改代码后刷新页面即可看到效果，无需重新构建
· 游戏内按 F3 可查看帧率、坐标、区块与面数等性能指标
· 调节渲染距离是优化帧率最直接的手段
· 若需调试渲染管线，可在浏览器开发者工具中直接访问全局对象

性能建议

设备 建议设置
低端设备 降低渲染距离、关闭平滑光照、关闭 FPS 显示
中端设备 中等渲染距离、开启平滑光照
高端设备 最大渲染距离、开启全部特效

常见问题

Q：页面打开后一片空白？
A：请确认使用的是本地服务器而非直接打开文件。若仍无效，请检查浏览器控制台是否有报错，并尝试更新浏览器。

Q：图片在 README 里不显示？
A：检查三点：① 图片是否已提交并推送；② 文件名大小写是否完全一致（GitHub 区分大小写）；③ 路径是否正确（相对路径或 Raw 链接）。

Q：游戏卡顿、帧率低？
A：进入设置降低渲染距离，并关闭平滑光照。也可以在游戏中按 F3 观察是哪一项指标偏高。

Q：存档丢失了？
A：存档保存在浏览器本地存储中。清除浏览器数据、使用无痕模式或更换浏览器都会导致存档不可见。

Q：能联机吗？
A：当前版本为纯前端单机体验，暂不支持多人联机。

Q：手机能玩吗？
A：目前主要针对桌面端键鼠操作设计，移动端适配仍在计划中。
